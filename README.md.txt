# Solo Real Estate Agent Software Finder

A free, SEO-optimized static website that helps solo real estate agents find the right software category.

## Pages

- Main software finder quiz
- Branch guide hub
- CRM branch page
- Automation branch page
- Marketing branch page

## Files

- `index.html` - Main quiz page
- `styles.css` - Shared styling
- `script.js` - Quiz logic
- `robots.txt` - Search engine crawling rules
- `sitemap.xml` - Sitemap for Google/Bing
- `404.html` - Custom 404 page
- `.nojekyll` - Prevents GitHub Pages Jekyll processing
- `branches/` - SEO branch pages
